# 多文件编辑汇总展示

日期：2026-11-10；状态：已实施

## 目标与范围

参考用户提供的 Codex CLI 截图，将连续文件修改展示为 `Edited N files (+A -D)`，下方按文件列出计数、有限的行号 diff 和详情入口，减少重复的 `Edit` 标题。保留已有图片输入改动，不改变 Host 工具执行、权限、Session 日志与 `/tools`、`/tool`、`/diff` 的索引和协议。

## 实施方案

- 聚合在 Transcript 展示层进行，原始工具块仍按 callId/subCallId 独立归并。仅接受成功结束且含实际 diff 的 `edit`、`apply_patch` 和已确认更新的 `write`；`write` 新建、运行中、失败、停止及没有 diff 的调用保留原有卡片。
- 原生调用保留 turn；PTC 子调用从 root/parent 调用继承 turn。只合并同一 turn 中相邻的合格修改，不跨过正文、通知或其他工具；无法确定 turn 的历史记录不跨调用合并。同一调用包含多个文件或同一文件的多个 hunk 也使用汇总展示。
- 成功的单次修改从一文件汇总开始，后续相邻修改在同一组件追加，保持已展示文件的布局稳定。相同路径只计一个文件，逐个保留 Host hunk，增删统计为应用操作的累计行数，不冒充最终净差异。
- 汇总与逐文件统计复用现有有界 diff 算法，保留 `~` 估算标记。默认每文件最多展示四行 diff，最多八个文件；展开后保留总行数与文件数上限。完整工具检查入口保持可用。路径和源码使用既有终端转义，窄屏按显示列宽裁剪。
- Host diff 路径作为文件身份保留；展示时将绝对路径转换为当前会话工作目录的相对路径，避免临时目录或仓库绝对路径遮挡文件名。切换工作目录时刷新相应组件。
- Ctrl+O 和全屏标题/详情入口点击切换详情；组件更新、追加成员、主题变化保留局部展开状态。窗口裁剪继续按原始块预算执行，汇总不绕过保留上限。
- 主屏已经滚出视口的同组汇总计数变化延迟到窗口尺寸变化后的重绘，新增文件继续追加，避免仅计数变化清除终端历史。实际 diff 内容变化、显式展开与窗口变化仍遵循 pi-tui 正常重绘。

## 影响区域

`edit-card.ts` 的统计复用，新增编辑组展示模块，Transcript 的 turn 投影、renderer 组件缓存和主屏计数刷新，以及对应测试、README 与真实 Host 探针。单个源码文件不超过 1000 行，不新增依赖。

## 验证与验收

- 回归覆盖原生/PTC、同一调用多文件/多 hunk、同路径累计、跨 turn/正文/通知/工具隔离、错误和部分停止、未知来源回退、估算统计与实际 diff 的一致性。
- 验证宽窄终端与 plain/dark/light、控制字符、预览上限、Ctrl+O、鼠标、缓存复用、主题刷新及保留窗口裁剪；主屏追加编辑不因屏外计数变化发出 `ESC[3J`。
- 运行针对性测试和 `pnpm check`。
- 使用隔离 profile、随机回环端口、本地 mock provider 与真实 Host，验证 standard/PTC、主屏/全屏的多文件实际落盘、汇总和逐文件 diff，以及展开和 `/diff` 索引。探针按 `dsh-ci-test-reliability` 约束等待帧和退出，并清理子进程、端口及临时目录。

## 实施与验证记录

- `pnpm check` 通过：111 个测试文件、1639 项测试，类型检查与构建通过。新增 31 项编辑组回归、2 项主屏历史保护/负对照、1 项真实全屏鼠标路由回归；更新既有展示断言，保留错误、源码和逐 hunk 断言。
- `node scripts/fake-tty-edit-group.mjs`：8 组全部 PASS，覆盖 standard/PTC × 主屏/全屏 × 100 列 dark / 50 列 light。实际修改四个文件，观察到 `Edited 4 files (+32 -32)`、逐文件 `(+8 -8)` 与行号 diff；Ctrl+O 展开/收起、`/diff` 最新/指定调用均正确；自动聚合未清除主屏历史，文字无行宽溢出。
- `node scripts/fake-tty-write-update-diff.mjs`：4 组全部 PASS，write 更新、已有空文件插入、新建源码展示、`/diff` 索引和配色保持正确。
- `node scripts/fake-tty-transcript-presentation.mjs`：6 组全部 PASS，允许/拒绝审批、错误状态、PTC compact/detailed、源码展开与主屏历史保护均正常。全屏拒绝场景下源码尾部被新增汇总区域移出视口；探针改为先观察明确的展开状态，再翻页验证源码，保留原有完整源码断言。
- 新探针及同步修改的探针脚本语法检查、`git diff --check` 通过。Host 探针均使用本地 mock provider，不代表外部真实模型或物理终端人工验收；本机端口监听与 PTC 内层沙箱经授权在沙箱外运行。
