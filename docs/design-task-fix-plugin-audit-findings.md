## 性能测量口径

Node v24.22.1，macOS；构建后的 JavaScript、普通 Node，测试数据由固定常量生成，不读取真实会话。记录全部样本及中位数；无跨机器耗时门槛。测试使用读取量、集合查询和输出语义断言，不依赖机器速度。

- 预览：128 MiB 稀疏文件，前 16 KiB 为文本；计时从 readTextPreview 调用至返回，排除文件创建和终端绘制。每次前执行 GC，结果返回时测量 ArrayBuffer 差值；修复前耗时 24.94/15.28/14.95 ms，ArrayBuffer 每次增加约 128 MiB。
- 冷回放：每 8 个工具调用一轮，read/bash 交替，路径 100 种，每个结果 30 行；maxEntries=600。计时包括生产 reducer.append/reduce，排除夹具创建、终端绘制和模型网络。修复前未插桩样本：

| 工具调用数 | 样本（ms） | 中位数（ms） |
|---:|---|---:|
| 2000 | 26.81 / 25.95 / 24.85 | 25.95 |
| 4000 | 85.00 / 83.20 / 84.20 | 84.20 |
| 8000 | 319.20 / 310.72 / 310.53 | 310.72 |
| 16000 | 1319.28 / 1304.78 / 1320.63 | 1319.28 |

本测量不代表完整终端交互或产品端到端延迟；保留对象仍可达时测量内存，不以丢弃输出作为优化。
